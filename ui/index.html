数据备份与恢复

备份包含本地对话、已确认记忆、人设版本、状态和生活事件；不会包含 .env、config.yaml 或日志。旧备份可能重新带回后来忘记的内容。

恢复前先关闭应用，在项目目录的 PowerShell 中运行：
python scripts\restore_backup.py --archive "C:\路径\备份.zip" --data-dir "C:\路径\wanwan-chatbot\data"
路径必须使用绝对路径。输入 RESTORE 后才会继续；运行中的应用会锁定恢复操作。恢复后再次启动，页面会生成新的本机会话令牌。
