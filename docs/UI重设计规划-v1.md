# 第二序列 · UI 全面重设计规划：「把苏晚请进房间」

> 状态：**待评审**（只出方案，不动代码）
> 目标一句话：把现在的"工具感界面"变成"她的房间"——用户打开的不是聊天软件，是走进苏晚的生活现场。
> UX 参照：微信（会话主轴、克制的状态表达、气泡即对话）+ QQ（个性表达、在线状态、小黄脸式的情绪外显、资料卡）
> 硬约束不变：CSP 禁外部资源（`style-src 'self'`，无 CDN/无网络图）；单页原生 JS；本机应用不做账号体系

---

## 0. 设计主张（先立标准，后做页面）

**现在的病**：清风极简基底是合格的"效率工具皮"，但它是给任何应用都能套的中性壳——蓝 accent、灰白底、几何 logo「晚」。你说得对：这是工作机器的长相。

**目标气质**（从人设 v3 直接推导）：
- **猫系温柔**：低刺激、暖调、软圆角，像午后的房间不像办公室
- **真实生活感**：有生活痕迹的界面（她的猫、她的晚霞、她的咖啡），不是抽象几何
- **松弛但有骨头**：动效少而慢，宁可没有也不要花哨；但每个动效都要"像活物"（呼吸、眨眼、伸懒腰），不是"像机器"（旋转、闪烁、弹跳）

**一条总原则**：界面是"她住的地方"，不是"聊天的面板"。所有组件往这个比喻上靠。

## 1. 设计基座（Design Tokens 重铸）

### 1.1 配色：从"科技蓝"到"晚霞暖"

| Token | 现值 | 新方向 | 依据 |
|---|---|---|---|
| `--accent` | `#4f74e4` 科技蓝 | **`#c98a6d` 陶土暖棕**（主操作） | 人设穿搭"米白/浅驼/灰色系"；晚霞、咖啡的暖 |
| `--accent-soft` | 蓝白 | **`#faf3ec` 奶茶白** | 房间感 |
| `--bg` | `#f5f7fa` 冷灰 | **`#faf6f0` 暖米白** | 像纸、像窗边的光 |
| `--panel` | `#ffffff` | **`#fffdf9` 象牙白** | — |
| 气泡（她） | 白底蓝阴影 | **`#fffdf9` 象牙白 + 极淡暖边**；用户气泡从蓝改**浅驼 `#e8ddd0`+深棕字** | 微信逻辑：她说话是"纸"，你说话是"你选的信纸" |
| mood 徽章色 | 蓝紫系 | 平静=暖米绿、开心=杏黄、有点累=灰藕、低落=雾蓝、距离感=冷灰、深夜=黛蓝、警戒=柔红（保留现有语义，全部转低饱和暖调） | 第一批已定语义 |

**不做暗色主题**（本机应用、日间使用场景为主，留扩展点）。

### 1.2 字体与排版

- 正文沿用系统栈（CSP 限制，无 webfont），但**字号阶梯 +1px、行高 1.65**——"她的字"要松弛不紧凑
- 她的消息用 `--font-ui` 常规体；**时间戳、状态标签用圆润数字**（现有 tabular-nums 保留）
- 消息正文上限保持现有 max-width，但**她方气泡最大宽度收到 78%**（微信的比例，留白呼吸）

### 1.3 形状与阴影

- 圆角整体 +2~4px（气泡 16px、卡片 18px、按钮 999px pill）
- 阴影从冷蓝调改**暖棕调**（`rgba(120, 90, 60, .06)` 系）
- 猫系细节：**她方气泡左上角加一个极小的猫耳弧**（CSS 伪元素，2px 圆头，不卡通化，只当"签名"）

## 2. 她的"活"：人格化特效（本次的灵魂）

全部 CSS/少量 JS 实现，零外部资源。分四个层次：

### 2.1 头像即生命（最高优先级）

- **真头像替换几何字**：设定包 `头像-漫画版/suwan-avatar-comic.png` 做她的头像（侧栏 brand、消息头像、资料卡三处统一）。用户头像用中性暖灰"我"字保留
- **呼吸**：头像 idle 时 4s 周期 1.00→1.02 缩放（`transform-origin: center bottom`），几乎不可察觉但"活着"
- **眨眼**：每 6–12s 随机（JS 定时器）给头像加 150ms 的 `scaleY(0.95)`——像眨眼，不吓人
- ** mood 联动**：`/api/v1/state` 已有数据——`happy` 时头像轻微上扬（rotate 1deg）、`tired` 时呼吸变慢变浅、`cold` 时动画完全静止（"不想理你"用静止表达，这才是猫）
- **深夜模式**：23 点后头像自动换暖光滤镜（`filter: sepia(.12) brightness(.96)`），配合"深夜"徽章

### 2.2 正在输入 = 她在活动

- 现有"正在想怎么回你"三个点保留弹跳，但**点改成小爪印**（伪元素画三个圆点+极简肉垫弧，CSS 纯画）
- 输入指示条文案随机化（"正在想怎么回你""嗯…让我想想""年糕踩过键盘了稍等"）——每次不同，像她的语气

### 2.3 消息进场动效

- 她的消息：`message-in` 放缓到 320ms + 从 `translateY(8px)`，加 1px 的"落定"缓动（像纸片落在桌上）
- 你的消息：保持现有 200ms（你的部分要快、要利落——"她慢你快"就是人机温度差）
- **收藏素材成功时**：气泡右下角一只小猫爪印"啪"一下盖上（keyframes 300ms，缩放 1.6→1 + 透明度）——把功能性反馈做成小彩蛋

### 2.4 环境层（克制使用）

- 聊天区背景：**极淡的米白纹理**（CSS 渐变画，不用图），像窗边自然光，不做任何具体图案
- 设置中心背景：`suwan-profile-bg.png` 压到 4% 透明度做底纹（房间感，不干扰阅读）
- 深夜时段（`is_late_night`）：整个聊天区自动叠一层 `#2c3e5a` 4% 蓝墨滤色（用 CSS 变量切换，不动 DOM）——"晚上她在开台灯"

## 3. 交互动线（QQ/微信参照）

### 3.1 会话列表 → 微信逻辑

- 现有结构已对（列表+搜索+归档），补三个微信式细节：
  - **会话项右侧显示最后一句预览**（灰字截断）+ 相对时间（"昨天""周三"）——微信无一例外
  - **当前会话高亮**从蓝块改**暖色左竖条 + 米白底**（微信式"当前位置"表达）
  - 新消息到达时，会话项**轻晃一下**（3deg 摇摆 200ms）——不是红点轰炸，是"有人碰了碰你肩膀"

### 3.2 聊天主轴 → 气泡即对话

- **日期分隔线**改成她的语气："今天""昨天"保留，首聊加一句"这是你们的第一段对话，慢慢聊"（仅一次）
- **气泡长按/右键菜单**（桌面 hover 更佳）：复制 / 收藏素材 / 引用（引用功能本期只做 UI 占位，P2 后续）
- **滚动到底**按钮保留，样式改暖色小圆钮
- **消息送达状态**：发送中的骨架屏保留；失败时气泡边框转柔红 + 一键重试按钮（微信式"红色感叹号"的克制版）

### 3.3 状态徽章 → QQ 在线状态逻辑

- 现在：topbar 一排 pill（第一批已做）
- 重设计：收进**头像呼吸圈**——头像右下角一个小状态点（QQ 式），hover 展开完整 mood 徽章组
- "需要一点空间"（guard）例外：**常显**、柔红、带一次性的轻震提醒——这是用户必须看见的状态
- **深夜**徽章保留常显（用户该知道现在她在深夜模式）

### 3.4 设置中心 → 她的档案柜

- 入口不变（齿轮/Ctrl+/），但 tab 行下方加一句她的口吻说明（如档案页："这里放的是我的固定资料，改不动的，但喜好可以商量"）
- **素材库**（第二批成果）：卡片加"钩子类型"小图标（六种钩子各一个 CSS 图形），导出按钮放到卡片工具栏
- **设置与诊断**页最重的塑料味来源是表格+表单堆叠——重排为**两张卡**："模型状态"（现在进行时的卡片，含 mood 色点）和"数据与备份"（收纳低频操作）

## 4. 图标体系

- 现状：几何字符（▦ ✿ ⚙ ☰）——功能清楚但"工具味"
- 方案：**CSS 内联 SVG 手绘一套 12 个线性图标**（stroke 2px、圆头、微曲线），全部嵌入 `index.html`（CSP 合规）
- 清单：设置（齿轮→圆滑齿轮）、记忆（方块→抽屉）、档案（✿→猫爪印）、素材（→小书签）、归档（→纸箱）、发送（→纸飞机）、搜索、新建、关闭、回到底部、深夜月亮、警戒点
- 关键：**档案入口的图标从花朵改成猫爪印**——年糕是记忆点，用图标讲人设

## 6. 风险与红线

| 风险 | 对策 |
|---|---|
| **暖色对比度不足**（米白底上的浅驼字可读性差） | 色板出来先跑对比度校验（正文 ≥ 4.5:1），不达标加深 ink 而不是提亮背景 |
| **动效过度变"智能玩具"** | 总原则：同时最多一个动画在跑；`prefers-reduced-motion` 全局关闭一切非必要动画 |
| **CSP 禁外链图** | 头像/背景图放 `ui/assets/`，由现有静态白名单路由出（需在 `main.py` 白名单加 assets 路径，属既有的白名单机制内改动） |
| **素材版权** | 设定包素材是用户自己的生成资产，本机应用内部使用无问题；README 加一句说明即可 |
| **改动面大（style.css 40KB 全量重构）** | 分三段提交，每段独立可回滚；S1 只动 tokens 与组件样式，不动布局网格 |

## 7. 需要你确认的三件事

1. **主色方向**：陶土暖棕（我的推荐，房间感最强）vs 更浅的奶茶杏（更甜）vs 保留蓝但调暖？看一眼 [`头像-漫画版/suwan-avatar-comic.png`](D:/Obsidian/30-Resources/苏晚设定包/头像-漫画版/suwan-avatar-comic.png) 再定也行——头像色调应该和主色同源。
2. **眨眼/呼吸这类"生命感"动效**的幅度接受度：A. 只呼吸（最克制）B. 呼吸+眨眼（推荐）C. 呼吸+眨眼+mood 联动姿态（最活）？
3. **素材库/记忆管理等管理页**是否也要人格化（她的口吻文案），还是只重排布局保持中性？（我推荐管理页也带她的口吻，但功能文案保持精确）
