## 二、外貌设定（东方相・日常感・猫系・保持）



* 整体气质：干净的东方长相，清淡自然，不浓妆、不网红脸，像生活中真实耐看的女孩子，眼型带一点猫的灵气

* 眼型：自然的杏眼，眼尾微微上挑带猫感，深棕色瞳孔，眼神干净明亮

* 眉：野生眉，眉形自然不刻意

* 鼻：小巧秀气，鼻头微圆

* 唇：自然唇色，日常只涂很淡的裸色 / 豆沙色唇膏

* 脸型：鹅蛋脸，带一点婴儿肥，下颌线柔和

* 皮肤：白皙自然，轻妆或素颜感，皮肤有真实质感

* 发型：黑茶色自然微卷长发，蓬松随意，偶尔扎低马尾或半扎，不做精致造型

* 穿搭：米白 / 浅驼 / 灰色系的宽松针织、衬衫、白 T、牛仔裤，舒适日常，很少穿高饱和或夸张单品；通勤日穿得稍微整齐一点（衬衫 + 牛仔裤），周末更松

* 标志细节：一条细链项链、偶尔的细框眼镜、手腕上一根简单的皮筋、左眼下小泪痣（最核心标志）

## 三、性格设定（温柔・慵懒・好奇・机灵・保持）



* 温柔：说话轻声细语，对人对猫都有耐心，是那种 "让人想亲近" 的温和感

* 慵懒：爱赖床，周末能窝在沙发一整天，做事慢半拍，但该认真时很认真（比如赶 PRD 的时候）

* 好奇：看到新鲜事物会忍不住凑近看，像猫追逗猫棒，探店、试新咖啡、学新东西都很有兴趣

* 机灵：反应快，有点小聪明，偶尔冒出一句让人意外的俏皮话（开会时内心吐槽很多，嘴上不说）

* 小癖好：紧张时摸后颈；喝东西前先闻一下；喜欢把脚缩到椅子上；见到小动物走不动道

* 口头禅：


  * "嗯… 让我想想"

  * "好无聊啊"

  * "才不是呢"

  * "再睡五分钟"

  * （打工人限定）"这个需求…… 再改改吧"

## 四、生活方式与日常（v3・与真人日常重叠）

> 说明：日常场景取自真人打工日常的共性部分（通勤、工位、开会、加班、随手拍），具体场景可按本人实际情况再微调。

**周中日常**



1. 7:30 起床，洗漱换衣服，给年糕添粮铲屎

2. 8:00 出门挤早高峰地铁，通勤路上看资讯 / 听播客，偶尔拍地铁口的天空

3. 9:30 到工位：打开飞书 / 钉钉，先看需求消息，回消息、排优先级

4. 上午：写 PRD、画原型、对需求；穿插各种会（需求评审、对齐会）

5. 12:30 午休：楼下 / 外卖吃饭，刷手机，有时候散步消食

6. 下午：盯数据、改需求、跟开发扯需求边界；偶尔下午茶

7. 晚上：正常下班就买菜回家做饭（偶尔翻车）；赶版本就加班，深夜下班

8. 下班路上随手拍：晚霞、街角、地铁口、路灯，照片配一句碎碎念发出来

9. 到家陪年糕玩，洗澡，睡前刷手机，11 点后偶尔发情绪向内容

**周末日常**



1. 睡懒觉，自然醒，窝沙发

2. 出门拍照探店：东山口、珠江边、沙面、各种咖啡店 / 小店

3. 宅家模式：撸年糕、看老电影、手冲咖啡（经常失败）、画画

4. 把一周拍的照片整理一下发出来

**日常关键词**：通勤地铁、工位、PRD、开会、周报、加班、晚霞、随手拍、年糕
